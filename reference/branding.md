# ใส่ CI ของลูกค้า (สี โลโก้ รูป)

หน้าตาเป็นธีมเดียวกันทุกงาน สิ่งที่เปลี่ยนตามลูกค้าได้คือ token สี, โลโก้ และรูปของแบรนด์ ฟอนต์ รูปทรง น้ำหนัก และสไตล์การ์ดเป็นของธีม

## สีมาจากไหน (ใช้แหล่งแรกที่มี)
0. เครื่องมือภายในที่ไม่มีลูกค้า: ใช้ design system ของทีม (teal `#0D9488` + ส้ม, ไอคอน SVG ไม่มี emoji · ที่อยู่ไฟล์และตัวอย่าง token ทั้ง 3 ชุดอยู่ใน `local/team-notes.md`) และทำโลโก้/สัญลักษณ์ของเครื่องมือนั้นเอง
   - ฟอนต์ของ design system ทีม (Inter) ไม่มีภาษาไทย ให้ใช้ Anuphan (ตัวเลขใช้ Inter ได้ถ้าต้องการ)
   - หน้าที่เป็นบอร์ดสถานะ ไม่ต้องใช้สีส้มของทีมเป็นสีเน้น เพราะจะอ่านเป็น "เตือน"
1. คู่มือ CI หรือ brand guideline ที่ลูกค้าส่งมา
2. CSS ของเว็บไซต์ลูกค้า: เปิดด้วย Playwright (`channel="chrome"`) แล้วอ่าน `getComputedStyle` ของหัวข้อ ปุ่มหลัก ลิงก์ และ footer (เว็บที่สร้างหน้าด้วย JavaScript อ่านจาก HTML ดิบไม่ได้)
3. สีจากโลโก้ (ใช้เป็นทางสุดท้าย) แล้วแจ้ง user ว่าเป็นสีที่เดาเอา

บันทึกที่มาของสีไว้ในคอมเมนต์หัวบล็อก tokens (`ถอดจาก CSS ของ www.example.com <วันที่>`)

## วางลง token
แก้ครบทั้ง 3 ชุด (`:root`, dark ใน media query, `[data-theme="dark"]`) ในทั้งสองไฟล์ login.html มี token น้อยกว่า dashboard.html ให้ใช้ค่าเดียวกันสำหรับ token ที่ชื่อตรงกัน

| token | ใส่อะไร |
|---|---|
| `--head` | สีหัวข้อ/ตัวเลข KPI (สีหลักโทนเข้ม) |
| `--primary`, `--primary-2` | ปุ่มหลัก และสีตอน hover |
| `--side` | ไล่สีแถบข้างจากสีหลักลงไปโทนเข้มสุด (ถ้าเว็บลูกค้ามี footer ไล่สี ให้ลอกจากตรงนั้น) |
| `--accent` | สีเน้นของแบรนด์: เมนูที่เลือก, focus ring, จุดบนปุ่ม |
| `--accent-ink` | สีเน้นที่ใช้เป็น**ตัวหนังสือ**ได้ (คอนทราสต์ ≥ 4.5:1 บน `--surface`) |
| `--nav-on-ink`, `--btn-dot-ink` | ตัวหนังสือที่วางบน `--accent` |
| `--bar`, `--s1..--s5` | สีข้อมูล: `--s1` สีหลัก, `--s2` สีเน้น, `--s3` สีรอง (ส้ม/เหลือง), `--s4` เทาฟ้า, `--s5` ลายเส้น |
| `--meter` | ไล่สีของหลอดโควตาหรือเป้า |
| `--stripe-1/2`, `--banner-img` | แถบเฉียงบนแบนเนอร์ และภาพแบนเนอร์ (`url(/assets/banner.jpg)` หรือ `none`) |
| `--on-primary` | ตัวหนังสือบนปุ่มหลัก ถ้าสีหลักเป็นสีอ่อน (ส้ม เหลือง) ให้ใช้สีเข้ม (มีทั้งสองหน้า) |
| `--font` | ฟอนต์ของธีม (Prompt) ไม่ต้องแก้ ถ้า CI ของลูกค้ากำหนดฟอนต์ ให้ถาม user ก่อน |
| `--mark-side`, `--avatar-bg` | สัญลักษณ์จางมุมล่างแถบข้าง และพื้นวงกลมหลัง avatar (โลโก้ที่ต้องอยู่บนพื้นเข้ม ให้ตั้งเป็นสีเข้ม) |
| `--mark-bg` | (เฉพาะ login.html) สัญลักษณ์จางมุมขวาล่าง |
| `--hero-img`, `--hero-bg`, `--hero-fade` | (เฉพาะ login.html) รูปการ์ดซ้าย, พื้นทึบ, และค่า RGB ของพื้น (คั่นด้วยจุลภาค) |
| `--ref`, `--ref-ink` | เส้นเป้า/เกณฑ์ในกราฟและป้ายของมัน (ไม่ตั้ง = สีเตือน) ถ้าเส้นนั้นคือเป้าหมาย ไม่ใช่คำเตือน ให้ใช้สีเน้นของแบรนด์ |
| `--crit-fill`, `--crit-on`, `--warn-fill`, `--warn-on` | สีทึบของการ์ดที่มีปัญหาบนจอทีวี และสีตัวหนังสือบนสีนั้น |

กติกาสี:
- สีเน้นที่คอนทราสต์บนพื้นขาวต่ำกว่า 4.5:1 (สีฟ้าอ่อน เหลือง เขียวมะนาว) ห้ามใช้เป็นตัวหนังสือ ให้ใช้ `--accent-ink` แทน
- สีแดงใช้กับแจ้งเตือนและสถานะเกินเพดานเท่านั้น ถ้าแบรนด์เป็นสีแดง ให้ใช้แดงของแบรนด์เป็น `--primary` แล้วเลือก `--crit` ให้ต่างจากแดงของแบรนด์อย่างชัดเจน
- `--s1..--s4` ต้องต่างกันทั้ง hue และความสว่าง คนตาบอดสีต้องแยกได้ ถ้ามีสกิล dataviz ให้ใช้ตัวตรวจ palette ของสกิลนั้น
- โหมดมืดไม่ได้กลับสีตรง ๆ: พื้นใช้ navy หรือเทาเข้มที่มีสีแบรนด์ปน, ทำสีข้อมูลให้สว่างขึ้น, ลด `--photo-op` ให้รูปจางลง

ตรวจคอนทราสต์ด้วยสคริปต์นี้ (WCAG):
```python
def lum(h):
    r, g, b = (int(h[i:i+2], 16) / 255 for i in (1, 3, 5))
    f = lambda c: c / 12.92 if c <= .03928 else ((c + .055) / 1.055) ** 2.4
    return .2126 * f(r) + .7152 * f(g) + .0722 * f(b)
def ratio(a, b):
    la, lb = sorted((lum(a), lum(b)), reverse=True); return (la + .05) / (lb + .05)
for fg, bg in [("#0B7285", "#FFFFFF"), ("#55687C", "#FFFFFF"), ("#5FD3E2", "#111F30")]:
    print(fg, bg, round(ratio(fg, bg), 2))   # ตัวหนังสือต้อง ≥ 4.5
```

## โลโก้และรูป (`/assets/`)

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `logo.svg` | การ์ด login (พื้นขาว) |
| `logo-white.svg` | แถบข้าง, การ์ดรูปบนหน้า login, การ์ด login ตอนโหมดมืด |
| `mark.svg` | favicon, avatar โปรไฟล์, avatar บอทในบทสนทนา, ลายจางบนหน้า login |
| `mark-white.svg` | แถบข้างตอนย่อ และลายจางมุมล่างแถบข้าง |
| `banner.jpg` (ถ้ามี) | `--banner-img` ชิดขวา และจางไปทางซ้ายเอง |
| `login-photo.jpg` (ถ้ามี) | `--hero-img` บนหน้า login |

- `/assets/` ต้องเปิดได้โดยไม่ต้อง login เพราะหน้า login ใช้ไฟล์ชุดเดียวกัน ถ้าโฟลเดอร์ dashboard อยู่หลัง auth ให้แยก assets ไว้ที่ path สาธารณะ
- รูปต้องเป็นของลูกค้าเท่านั้น (จากเว็บไซต์หรือเอกสารของลูกค้าเอง เช่น One Report) ห้ามใช้รูปที่มีโลโก้ของบริษัทอื่น ถ้าจำเป็นต้องใช้รูป CC ต้องคงเครดิตไว้บนหน้า และบอก user
- โลโก้ควรเป็น SVG ถ้าลูกค้ามีแต่ PNG ให้ใช้ขนาด 2x ขึ้นไป ไฟล์ทุกตัวเปลี่ยนนามสกุลได้โดยไม่ต้องแตะ ENGINE: `<img>` ใน HTML กับ favicon แก้ตรง ๆ ส่วน `--mark-side`/`--mark-bg` แก้ที่ token และ avatar แก้ที่ `BRAND.mark`
- ถ้าไม่มีสัญลักษณ์สีขาว ให้ทำจากไฟล์สีโดยเปลี่ยนเป็นสีขาวทั้งหมดแต่คง alpha ไว้ (ใช้ Pillow)
- ห้ามใช้ asset ของลูกค้ารายอื่นข้ามโปรเจกต์ แม้จะอยู่ VPS เดียวกัน

## ฟอนต์
- ทุกหน้าใช้ฟอนต์ของธีม (Prompt จาก Google Fonts) ไม่เปลี่ยนตามลูกค้า ถ้า CI ของลูกค้ากำหนดฟอนต์ไว้ ให้ถาม user ก่อนเปลี่ยน
- ตรวจคอนทราสต์ของ token ทั้งชุดด้วย `python3 design/check_tokens.py <ไฟล์>` (ครอบคลุมทุกคู่และทั้งสองโหมด)
