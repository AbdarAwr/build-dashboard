# สัญญาของ CONFIG (`<script id="dash-config">` ใน template/dashboard.html)

หน้า dashboard มีสองส่วน:
- **ENGINE** (`<script id="dash-engine">`) เป็นโค้ดชุดเดียวกันทุกโปรเจกต์ ห้ามแก้ในโปรเจกต์ ถ้าต้องแก้ ให้แก้ในแม่แบบของสกิล รันเทสต์ แล้วพอร์ตไปทุกโปรเจกต์
- **CONFIG** (`<script id="dash-config">`) เป็นส่วนเดียวที่ปรับ จบด้วย `start({...})`

ช่องทั้งหมดที่ต้องแก้มีป้าย `[แก้ N]` / `[แก้]` ให้ grep หาได้: `grep -n "\[แก้" dashboard.html login.html`

## ค่าระดับบนที่ส่งให้ `start()`

| ช่อง | บังคับ | ความหมาย |
|---|---|---|
| `brand` | ✓ | `{ name, product, tagline, footer, mark, role }` แสดงบนแบนเนอร์ แถบข้าง และ `<title>` ส่วน `mark` คือรูปบน avatar (ค่าเริ่มต้น `/assets/mark.svg`) ชื่อบนแบนเนอร์ควรสั้น ถ้ายาวเกินจะถูกตัดด้วย … · `role` = คำบนปุ่มโปรไฟล์แทน "ผู้ดูแลระบบ" (หน้าที่ลูกค้าหรือผู้บริหารใช้ เช่น `'ผู้บริหาร'`) |
| `auth` | – | ตั้งจาก `const AUTH` (`[แก้ 5]`) · `false` = ไม่มีระบบ login: ปุ่มโปรไฟล์กลายเป็น "ตั้งค่าการแสดงผล" ไม่มีเมนูออกจากระบบ และโหลดไม่ได้จะขึ้นปุ่ม "ลองใหม่" แทน "เข้าสู่ระบบ" (ดู `serving.md`) |
| `layout` | – | ลำดับ section บนหน้าภาพรวม จาก `'kpis' 'trend' 'breakdown' 'rankings' 'table'` (ค่าเริ่มต้น `['kpis', 'trend', 'rankings', 'table']`) ตัด section ที่ไม่ต้องการออกได้ ยกเว้น kpis กับ table ที่มีเสมอ · breakdown อยู่ข้างกราฟ เว้นแต่ใส่ `'breakdown'` เองจึงได้แถวของตัวเอง · วิธีเลือกอยู่ใน `layout.md` |
| `unit` | ✓ | คำนามของแถวที่นับ เช่น `'คำถาม'`, `'คำสั่งซื้อ'` |
| `exportName` | ✓ | ชื่อไฟล์ CSV ที่ส่งออก (`<exportName>-<from>_<to>.csv`) |
| `defaultRange` | – | ช่วงเวลาตอนเปิดหน้า: `'all'` (ค่าเริ่มต้น), `'today'`, `'7'`, `'30'`, `'month'`, `'year'` |
| `refreshSec` | – | รีเฟรชอัตโนมัติทุกกี่วินาที (ค่าเริ่มต้น 300, ต่ำสุด 30) ข้อความบนหน้าเปลี่ยนตาม |
| `data` | ✓ | วิธีโหลดและแปลงข้อมูล (ดูหัวข้อถัดไป) |
| `counted(row)` | – | แถวไหนนับใน KPI / กราฟ / อันดับ (ค่าเริ่มต้นนับทุกแถว) แถวที่ไม่นับยังอยู่ในตารางและสัดส่วน |
| `kpis(ctx)` | ✓ | คืน array ของการ์ด KPI จำนวน 2–4 ใบ |
| `trend` | – | `{ title, unit, value(row), fmt }` กราฟแท่งตามเวลา: `value` เป็นค่าต่อแถว (ค่าเริ่มต้น 1 = นับแถว ถ้าเป็นยอดเงินให้ใส่ `l => l.amount`) · หลายตัวเลข: `{ metrics: [{ key, label, title, unit, value, fmt, at, agg, ref }, ...] }` ได้ปุ่มสลับบนการ์ดกราฟ ตัวแรกเป็นค่าเริ่มต้น · `at(row)` = นับตามเวลาอื่นของแถว (เวลาปิด/ชำระ/เสร็จ) และกรองช่วงด้วยเวลานั้น · `agg(rows)` = ค่าต่อแท่งที่รวมกันไม่ได้ (อัตรา %, ค่าเฉลี่ย, p95) แทนการรวม `value` แท่งที่ไม่มีแถวแสดง "ไม่มีข้อมูล" (ไม่ใช่ 0) · `ref: { value, label }` = เส้นเกณฑ์ประบนกราฟ (SLA 90%, p95 8,000 ms) · `min` = จำนวนแถวขั้นต่ำต่อแท่งของ `agg` (น้อยกว่านั้นเป็น "ไม่มีข้อมูล") · `peak: 'min'` = คำบรรยายและป้ายบนแท่งเน้นค่าต่ำสุด (ตัวเลขที่ยิ่งต่ำยิ่งแย่ เช่น SLA %) · `max` = เพดานแกน Y แท่งที่เกินถูกตัดพร้อมป้ายค่าจริง (กัน timeout ครั้งเดียวทำให้กราฟแบน) |
| `breakdown` | – | การ์ดสัดส่วน (รวม 100%) และ dropdown กรองตาราง |
| `rankings` | – | array ของการ์ดอันดับ (top N) แสดงสองใบต่อแถว |
| `table` | ✓ | ตารางรายการแบบแบ่งหน้า |
| `detail` | – | มุมมองที่สอง `#<route>` (รายการกลุ่มด้านซ้าย เนื้อหาด้านขวา) ถ้าเป็น `null` เมนูข้างจะเหลือ "ภาพรวม" อย่างเดียว |
| `notifs(n)` | – | รายการในกระดิ่งแจ้งเตือน ถ้าไม่ใส่ กระดิ่งจะซ่อน |

## data

```js
data: {
  url: '/api/logs.csv?limit=50000',  // same-origin, ผ่าน login gate (ส่ง cookie)
  format: 'csv',                      // 'csv' | 'json' (array หรือ { rows|data|logs: [...] })
  limit: 50000,                       // ถ้าได้แถว >= limit จะเตือนใต้หัวหน้าว่าข้อมูลอาจไม่ครบ
  required: ['timestamp', 'session'], // ถ้าไม่มีคอลัมน์เหล่านี้ จะขึ้นการ์ด "รูปแบบข้อมูลผิด"
  time: r => r.timestamp,             // ISO มีโซน (+07:00/Z) ใช้ตามนั้น · ไม่มีโซน ('2026-10-14 09:30' หรือ '2026-10-14') = เวลาไทย
                                      // รูปแบบอื่น (เช่น 14/10/2569) ต้องแปลงใน time() ให้เป็น ISO ก่อน
  keep: r => isUUID(r.session),       // ตัดแถวทดสอบ/ขยะ ก่อนทุกมุมมอง (ใช้ตัวกรองนี้ตัวเดียวทั้งหน้า)
  toRow: r => ({ ... }),              // แปลง record ดิบ → ฟิลด์ที่หน้าใช้ (ห้ามตั้ง id/raw/ms/day/hour เพราะ engine ใส่ให้)
  hay: l => [ ... ],                  // ข้อความที่ช่องค้นหาค้นได้ (engine เติมเวลาและป้ายให้เอง)
}
```

engine เพิ่มฟิลด์ให้ทุกแถว: `id, raw, ms, day ('YYYY-MM-DD' วันไทย), hour (ชั่วโมงไทย), counted, group, tags, hay`
**ชื่อเหล่านี้สงวนไว้** ถ้าต้นทางมีคอลัมน์ชื่อซ้ำ (เช่น `tags` ของ ticket) ให้ตั้งชื่ออื่นใน `toRow` (เช่น `labels`) ไม่งั้นค่าจะถูกทับเงียบ ๆ

## kpis(ctx)

`ctx = { rows, counted, all, monthCounted, bounds, isAll, today, month, now, rangeKey, rangeText, rangeName, label(noun) }`
- `rows` คือทุกแถวในช่วงที่เลือก, `counted` คือเฉพาะแถวที่นับ, `monthCounted` คือแถวที่นับของเดือนปฏิทินปัจจุบัน (เวลาไทย) ไม่ขึ้นกับช่วงที่เลือก
- `all` คือทุกแถวไม่ขึ้นกับช่วง ใช้กับตัวเลข "ตอนนี้" (งานค้าง, ticket ที่เปิดอยู่) · `now` คือเวลาปัจจุบันเป็น ms ใช้คำนวณอายุ/รอนานเท่าไร (ส่วนวันที่ให้ใช้ `day`/`today` ของ engine)
- `label('คำถาม')` ได้ข้อความตามช่วงที่เลือก เช่น 'คำถามวันนี้', 'คำถาม 7 วันล่าสุด', 'คำถามทั้งหมด', 'คำถามในช่วงที่เลือก'

การ์ดหนึ่งใบเขียนแบบนี้: `{ icon, id, label, value, hint, meter, status, go }`
- `icon` เป็นชื่อไอคอนใน `ICON` ได้แก่ chat, users, gauge, target, money, box, chart, clock, cal, image, sales, mail, list, logs, alert, warn, check, bell (ถ้าต้องการไอคอนอื่น ให้เพิ่มใน ENGINE ของแม่แบบ)
- `id` ใส่ที่ตัวเลขหลัก เทสต์อ่านค่าจาก `#<id>`
- `label` / `hint` / `value` เป็น HTML ข้อมูลที่มาจากผู้ใช้ต้องผ่าน `esc()` ก่อนเสมอ
- `value` ที่ยาวเกินประมาณ 9 ตัวอักษร (เช่น 6,741,095) ให้ใช้ `fmtCompact(n)` แล้วใส่ตัวเลขเต็มไว้ใน `hint` engine ย่อขนาดตัวอักษรตามความกว้างการ์ดให้แล้ว แต่ตัวเลขยาวจะเล็กจนอ่านยาก
- `status: { tone: 'ok'|'warn'|'crit'|'', text }` ป้ายสถานะข้างตัวเลข (tone ว่าง = ยังตัดสินไม่ได้ เช่น "ข้อมูลน้อย" แสดงเป็นป้ายสีกลาง) (สี + ไอคอน + คำ) สำหรับตัวเลขที่มีเกณฑ์แต่ไม่ใช่เพดาน/เป้ารายเดือน เช่น อัตราผิดพลาด, SLA % (ใช้ไม่ได้พร้อม `meter`)
- `go: { text, filter: row => bool, allTime, type, query }` ปุ่ม "ดูรายการ" ใต้การ์ด เปิดตารางที่กรองตรงตัวด้วย `filter` (แสดงเป็นชิปที่กดล้างได้) และ/หรือกลุ่ม `type` / คำค้น `query` · การ์ด "ตอนนี้" ต้องใส่ `allTime: true` ตารางจะเปลี่ยนเป็น "ทั้งหมด" ให้จำนวนแถวตรงกับตัวเลขบนการ์ด · หน้าต่างเวลาเลื่อน (24 ชม. ล่าสุด) ใส่ใน `filter` ด้วย `ctx.now`
- `meter` คือหลอดเทียบเพดานหรือเป้า: `{ kind: 'limit'|'goal', used, max, unit, fmt, warnAt: 80, warnText, critText, doneText, note, label }`
  - `limit` คือเพดาน เช่นโควตา: 80% ขึ้นป้ายส้ม 100% ขึ้นป้ายแดง และกระดิ่งควรเตือน
  - `goal` คือเป้า เช่นยอดขาย: ถึง 100% ขึ้นป้ายสีเน้น "ถึงเป้าแล้ว"
  - ถ้าไม่ใส่ `hint` engine จะเขียนให้เอง (ใช้ไป/เหลือ หรือทำได้/ขาดอีก ต่อด้วย `note`)

## breakdown

```js
breakdown: { title, cap, unit: 'ข้อความ', groups: { key: { name, color: 'var(--s1)' } }, order: [...],
             optional: ['other'],       // กลุ่มที่ซ่อนเมื่อเป็น 0
             scope: 'all' | 'counted',  // ค่าเริ่มต้น 'all'
             value: row => number,      // (ไม่บังคับ) รวมค่าแทนการนับแถว เช่น ยอดเงินต่อภูมิภาค + fmt
             filterAll: 'ทุกภูมิภาค',     // ข้อความตัวเลือกแรกของ dropdown กรองตาราง (ค่าเริ่มต้น 'ทุกประเภท')
             allTime: true,             // (ไม่บังคับ) สถานะ ณ ตอนนี้ ไม่ขึ้นกับช่วงที่เลือก · กดกลุ่มแล้วตารางเปลี่ยนเป็น "ทั้งหมด" ให้ตัวเลขตรงกัน
             of: row => key }           // แต่ละแถวต้องอยู่กลุ่มเดียว ตัดสินตามลำดับความสำคัญ
```
เปอร์เซ็นต์ปัดแบบ largest remainder ให้รวมเป็น 100 พอดี กดชื่อกลุ่มแล้วตารางจะกรองเฉพาะกลุ่มนั้น สีใช้ `--s1..--s5` จึงมีได้ไม่เกิน 5 กลุ่ม ถ้าค่าเปิด (เช่นชื่อภูมิภาค) อาจมีมากกว่านั้น ให้ `of()` จัดค่าที่เหลือเข้ากลุ่ม "อื่น ๆ / ไม่ระบุ" และใช้การ์ดอันดับแสดงรายการเต็ม

## rankings

`{ title, cap, keys: row => string | string[] | null, value?: row => number, agg?: rows => number, min?, fmt?, top: 10, allTime?, go? }`
- นับจากแถวที่ `counted` ในช่วงที่เลือก ถ้า keys คืน array จะนับทุกคำ (ซ้ำในแถวเดียวกันนับครั้งเดียว) ถ้าคืน `null` แถวนั้นไม่ถูกนับ (ใช้จัดอันดับเฉพาะแถวที่สนใจ เช่น ที่ผิดพลาด)
- `value` = เรียงตามผลรวมของค่านั้น เช่นยอดเงิน · `agg(rows)` = ค่าต่อกลุ่มแบบอื่น เช่น อัตรา %, ค่าเฉลี่ย, มัธยฐาน (ใช้กับ `min` = จำนวนแถวขั้นต่ำต่อกลุ่ม กันกลุ่มเล็กขึ้นอันดับ) · เรียงจากมากไปน้อยเสมอ
- `allTime: true` = ไม่ขึ้นกับช่วงที่เลือก (หัวการ์ดขึ้น "ไม่ขึ้นกับช่วงเวลา" ให้เอง) · `go: true` = กดแถวแล้วตารางเหลือเฉพาะแถวที่การ์ดนับให้ชื่อนั้นพอดี (ตรงตัว ไม่ใช่ค้นข้อความ) ถ้าเป็น `allTime` ตารางจะเปลี่ยนเป็น "ทั้งหมด" ให้

## table

```js
table: { title, cap, search: 'placeholder…', timeHead: 'เวลา',
  sort: (a, b) => number,                    // (ไม่บังคับ) ลำดับแถว ค่าเริ่มต้นใหม่สุดอยู่บน เช่น งานค้างเก่าสุดก่อน: (a, b) => a.ms - b.ms
  tags: row => [[ข้อความ, สี], ...],          // ป้ายหน้าข้อความ ใช้ tagsHtml(l) ในคอลัมน์
  columns: [{ head, width, align: 'right', cls: 'main'|'a'|'im'|'mono'|'num', cell: row => HTML }] }
```
- คอลัมน์ "เวลา" อยู่แรกเสมอ ถ้ามี `detail` จะมีปุ่มเปิดรายละเอียดอยู่ท้ายแถว
- ตารางแสดงทุกแถวในช่วง ใหม่สุดอยู่บน (หรือตาม `sort`) หน้าละ 10 แถว ไม่ตัดจำนวน
- บนจอมือถือ (≤600px) แต่ละแถวกลายเป็นการ์ด คอลัมน์ที่มี `cls: 'main'` เป็นตัวหนา เซลล์ว่างจะซ่อน และคอลัมน์อื่น (ยกเว้น `main`/`a`) มีชื่อคอลัมน์นำหน้าให้เอง จึงควรตั้ง `head` ให้สั้นและสื่อความ

## detail (มุมมองที่สอง)

```js
detail: { route: 'logs', nav: 'ประวัติการสนทนา', icon: 'logs', open: 'เปิดบทสนทนา',
  unit: 'ข้อความ', groupUnit: 'sessions', keyLabel: 'Session', back, pick, search,
  key: row => groupKey, shortKey: k => …,
  order: 'newest',                        // (ไม่บังคับ) ในหนึ่งกลุ่มเรียงใหม่สุดก่อน (ค่าเริ่มต้นเก่าไปใหม่ เหมาะกับบทสนทนา)
  openIcon: 'right',                      // (ไม่บังคับ) ไอคอนปุ่มเปิดท้ายแถวตาราง ค่าเริ่มต้นเป็นรูปบทสนทนา · ข้อมูลอื่นใช้ 'right' ('arrow' ดูเหมือนลิงก์ออกนอกเว็บ)
  copyKey: false,                         // (ไม่บังคับ) key เป็นชื่อ (ลูกค้า, ฟีเจอร์) → แสดงเป็นหัวข้อ ไม่ใช่รหัส monospace + ปุ่มคัดลอก
  groupSort: (a, b) => number,            // (ไม่บังคับ) ลำดับรายการด้านซ้าย a/b = { key, recs } เช่น เกิน SLA ก่อน · ค่าเริ่มต้นล่าสุดอยู่บน
  listItem: (key, recs) => ({ title, meta /* HTML */ }),
  head: (key, allRecsOfKey, recsInRange) => HTML,   // ข้อมูลเพิ่มบนหัว เช่นอีเมล หรือสรุปของช่วงที่เลือก
  render: row => Element | HTML }         // หนึ่งแถวในเนื้อหาด้านขวา
```
`render` เลือกตามชนิดข้อมูล (ตารางใน `layout.md`): บทสนทนาใช้โครง `turnEl` ของ preset chatbot ส่วนข้อมูลอื่นใช้ตัวช่วยของ engine
- `recordHtml({ title, sub, tags: [[ข้อความ, สี]], fields: [[ป้าย, HTML]], body: HTML, foot: HTML })` ได้การ์ดระเบียน (หัว + ป้าย + ช่องข้อมูล + เนื้อหา) ค่าใน fields, body และ foot เป็น HTML จึงต้อง `esc()` เอง
- `timelineHtml([{ time, title, text: HTML, tone: ''|'ok'|'warn'|'crit' }])` ได้ลำดับเหตุการณ์
URL ที่ใช้คือ `#<route>` และ `#<route>/<key>` ตัวกรองช่วงเวลาใช้ร่วมกับหน้าภาพรวม
ถ้าเปิด `#<route>/<key>` จากลิงก์ กระดิ่ง หรือบุ๊กมาร์ก แล้วช่วงที่เลือกไม่ครอบรายการนั้น หน้าจะแสดงรายการนั้นทั้งหมดพร้อมบอกว่าอยู่นอกช่วง
ถ้าหนึ่งแถวคือหนึ่งระเบียน (key ไม่ซ้ำ เช่น ticket_id) หัวและข้อความบนหน้าจะไม่พิมพ์จำนวนซ้ำให้เอง
ปุ่มเปิดท้ายแถวตารางพาไปที่กลุ่มของแถวนั้น แล้วเลื่อนไปเน้นระเบียนที่กดมา (กลุ่มเป็นลูกค้าหรือฟีเจอร์ก็ยังเจอแถวที่ต้องการ)

## notifs(n)

`n = { since, all, today, month, now, monthCounted }` คืน `[{ tone: ''|'warn'|'crit'|'ok', icon, title, text, go, key? }]`
- `go: { filter, text, type, query }` จะเปิดตาราง (ช่วง "ทั้งหมด") ที่กรองตรงตัวด้วย `filter` และ/หรือกลุ่ม `type` / คำค้น `query` ส่วน `go: 'top'` จะเลื่อนขึ้นบนสุด
- ถ้ามี `key` ถือเป็นการเตือนค้าง อ่านแล้วจะไม่นับซ้ำจนกว่า key เปลี่ยน (เช่น `quota-2026-10-80`) ถ้าไม่มี key จะนับเป็นของใหม่ (ใช้กับ "ตั้งแต่ `since`")
